================================================================================
                  RENDER ENVIRONMENT VARIABLES - VISUAL GUIDE
                      How to set DATABASE_URL correctly
================================================================================

THE PROBLEM:
  Your app on Render is trying to connect to localhost:5432
  But localhost doesn't exist on Render's servers!
  
  Solution: Set DATABASE_URL environment variable to Render's PostgreSQL

================================================================================
                        WHERE TO SET VARIABLES
================================================================================

1. Go to: https://render.com/dashboard
2. Find your Web Service: medical-cdss
3. Click on it
4. Go to: Settings tab (right side)
5. Scroll down to: Environment (section)
6. Click: "Add Environment Variable"

================================================================================
                    WHAT TO ADD (EXACT FORMAT)
================================================================================

Variable 1: DATABASE_URL
─────────────────────────

Key:   DATABASE_URL

Value: postgresql://postgres:XXXXXXXXXXXXX@dpg-xxxxx.oregon-postgres.render.com:5432/medical_cdss

Where XXXXXXXXXXXXX is your actual password from PostgreSQL database!


Variable 2: FLASK_ENV
─────────────────────

Key:   FLASK_ENV

Value: production


Variable 3: FLASK_DEBUG
────────────────────────

Key:   FLASK_DEBUG

Value: False

================================================================================
                        HOW TO GET CONNECTION STRING
================================================================================

1. Go to: https://render.com/dashboard
2. Click: PostgreSQL database (e.g., medical-cdss-db)
3. Look for: "Connections"
4. Copy: "PostgreSQL Connection String"
   
   It looks like:
   postgresql://postgres:abc123@dpg-xxxxx.oregon-postgres.render.com:5432/medical_cdss

5. Paste this in DATABASE_URL environment variable

================================================================================
                      ERROR MESSAGES & SOLUTIONS
================================================================================

Error: "No DATABASE_URL environment variable found"
→ DATABASE_URL not set in Environment section
→ Solution: Add it now following steps above

Error: "connection to server at localhost failed"
→ App trying to use localhost instead of Render PostgreSQL
→ Solution: Make sure DATABASE_URL is set correctly

Error: "password authentication failed"
→ Wrong password in CONNECTION string
→ Solution: Copy exact connection string from PostgreSQL service

Error: "Worker failed to boot"
→ Something wrong with app startup
→ Solution: Check logs for specific error, fix locally first

================================================================================
                        QUICK REFERENCE
================================================================================

DATABASE_URL Format:
postgresql://username:password@hostname:port/database

Example:
postgresql://postgres:abc123@dpg-xxxxx.oregon-postgres.render.com:5432/medical_cdss

Key Points:
  - Start with: postgresql://
  - Username: postgres
  - Password: From your PostgreSQL service
  - Hostname: From your PostgreSQL service (NOT localhost!)
  - Port: 5432
  - Database: medical_cdss
