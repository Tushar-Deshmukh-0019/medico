ENVIRONMENT VARIABLES (CRITICAL)
================================================================================

Must be set in Render Web Service Settings → Environment:

DATABASE_URL
  - Get from: Render PostgreSQL service → Internal Database URL
  - Format: postgresql://user:pass@host:port/database
  - Required: YES (app will fail without it)

FLASK_ENV
  - Value: production
  - Required: YES

FLASK_DEBUG
  - Value: False
  - Required: YES

SECRET_KEY
  - Value: Random string (generate with: python -c "import os; print(os.urandom(16).hex())")
  - Required: YES

All 4 MUST be set for production deployment.

================================================================================
TROUBLESHOOTING QUICK LINKS
================================================================================

"DATABASE_URL not set"
→ Check: Render Web Service Settings → Environment
→ Fix: Add DATABASE_URL with PostgreSQL connection string

"Connection refused"
→ Cause: Using localhost instead of Render PostgreSQL
→ Fix: Set DATABASE_URL to Render's PostgreSQL URL

"App won't start"
→ Check: Render Logs tab
→ Look for Python errors
→ Verify all imports work locally

"Deployment fails"
→ Check: Build Logs tab
→ Look for dependency errors
→ Run: pip install -r requirements.txt

Full troubleshooting: RENDER_DEPLOYMENT_CHECKLIST.md
