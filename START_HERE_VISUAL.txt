🆘 QUICK TROUBLESHOOTING:

Problem: "psql: command not found"
Solution: Add PostgreSQL to PATH or use full path:
          "C:\Program Files\PostgreSQL\15\bin\psql" -U postgres

Problem: "Connection refused"
Solution: Start PostgreSQL service in Windows Services

Problem: "Database does not exist"
Solution: Run: psql -U postgres -f setup_database.sql

Problem: "Port 5000 already in use"
Solution: Try different port: python app.py --port 5001

Problem: "Setup script fails"
Solution: Read POSTGRES_WINDOWS_SETUP.md troubleshooting section

For more help: See SETUP_INDEX.md or search specific guide
