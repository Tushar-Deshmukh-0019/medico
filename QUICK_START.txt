FUZZY LOGIC MEDICAL DECISION SUPPORT SYSTEM - QUICK START
================================================================================

🚀 GET STARTED IN 5 MINUTES

Step 1: Open Command Prompt/PowerShell
   └─ Navigate to: c:\medical_cdss

Step 2: Create Virtual Environment
   └─ Command: python -m venv venv
   └─ Activate: venv\Scripts\activate

Step 3: Install Dependencies
   └─ Command: pip install -r requirements.txt

Step 4: Run Application
   └─ Command: python app.py
   └─ Wait for: "Running on http://127.0.0.1:5000"

Step 5: Open Browser
   └─ URL: http://localhost:5000
   └─ Enjoy! 🎉

TROUBLESHOOTING
================================================================================

❌ "Python not found"
   └─ Install Python from python.org

❌ "Port 5000 already in use"
   └─ Edit app.py, change port: app.run(..., port=5001)

❌ "Module not found"
   └─ Ensure virtual environment is activated
   └─ Run: pip install -r requirements.txt

❌ "Connection refused"
   └─ Check if Flask is running
   └─ Wait 10 seconds for server to start

================================================================================
FUZZY LOGIC PRIMER
================================================================================

Traditional Logic:
  Blood Sugar = 125 mg/dL → "High" (crisp, binary)

Fuzzy Logic:
  Blood Sugar = 125 mg/dL → 60% High, 30% Slightly High, 10% Normal
  
This mimics how doctors think: parameters exist in fuzzy ranges!
