                            RELATIONSHIP DIAGRAM

┌──────────────────────┐                    ┌──────────────────────────┐
│   PATIENTS TABLE     │                    │  ASSESSMENTS TABLE       │
├──────────────────────┤                    ├──────────────────────────┤

│   age                │                 └──┤   blood_sugar           │
│   email              │                    │   bmi                   │

│                      │                    │   risk_category         │
│  (1 Patient)         │                    │   recommendations       │
│  (Many Assessments)  │                    │   created_at            │
│                      │                    │   updated_at            │
└──────────────────────┘                    │  (Many Assessments)     │
                                             │  (One Patient)          │
       ↑                                      │                        │
       │                                      └──────────────────────────┘
       │
    1:N Relationship
    (One patient has many assessments)

Explanation:
  • patients.id is the primary key
  • assessments.patient_id is a foreign key pointing to patients.id
  • This creates a relationship: One patient → Many assessments
  • When viewing assessment, you can see which patient it belongs to

What gets stored:

Step 1: Create Patient
  INSERT INTO patients (name, age, email, phone) 
  VALUES ('John Smith', 45, 'john@email.com', '555-1234');
  → Generates patient.id = 1

Step 2: Create Assessment
  INSERT INTO assessments (patient_id, blood_sugar, bmi, age, bp, risk_score...)
  VALUES (1, 150, 28, 45, 130, 72.5, 'High'...);
  → Links to patient with id=1

Step 3: View in pgAdmin
  → See patient record
  → See assessment record
  → See they're linked via patient_id

================================================================================
                          EXAMPLE QUERIES
================================================================================

To explore your data in pgAdmin Query Tool:

1. See all patients:
   ┌─────────────────────────────────┐
   │ SELECT * FROM patients;         │
   └─────────────────────────────────┘

2. See all assessments:
   ┌─────────────────────────────────┐
   │ SELECT * FROM assessments;      │
   └─────────────────────────────────┘

3. Count total patients:
   ┌─────────────────────────────────┐
   │ SELECT COUNT(*) FROM patients;  │
   └─────────────────────────────────┘

4. Average risk score:
   ┌──────────────────────────────────────┐
   │ SELECT AVG(risk_score)               │
   │ FROM assessments;                    │
   └──────────────────────────────────────┘

5. High-risk patients (> 70%):
   ┌──────────────────────────────────────┐
   │ SELECT * FROM assessments            │
   │ WHERE risk_score > 70;               │
   └──────────────────────────────────────┘

6. Patient with their assessments:
   ┌────────────────────────────────────────────┐
   │ SELECT p.name, a.risk_score,               │
   │        a.created_at                        │
   │ FROM patients p                            │
   │ JOIN assessments a ON p.id = a.patient_id; │
   └────────────────────────────────────────────┘
