================================================================================
                      pgAdmin Quick Start Guide
                  View Your Medical CDSS Database Locally
================================================================================

WHAT IS pgAdmin?
  → Visual tool to manage PostgreSQL databases
  → View tables, data, structure, relationships
  → Run SQL queries
  → No command line needed!

================================================================================
                          INSTALLATION
================================================================================

1. Download pgAdmin 4 for Windows
   https://www.pgadmin.org/download/pgadmin-4-windows/

2. Run installer

3. Set master password (remember it!)

4. Finish installation

5. Browser opens automatically to:
   http://localhost:5050

Done! pgAdmin is ready.

================================================================================
                      CONNECT TO YOUR DATABASE
================================================================================

In pgAdmin:

1. Right-click "Servers" (left sidebar)
2. Click "Create" → "Server"
3. Fill in connection details:
   
   Name:     medical_cdss
   Host:     localhost
   Port:     5432
   User:     postgres
   Password: <your-password>
   
4. Click "Save"

5. Expand Servers → localhost → Databases → medical_cdss

Done! Connected to your database.

================================================================================
                        VIEW YOUR TABLES
================================================================================

Navigate to your tables:

  Servers
    → localhost (your server)
      → Databases
        → medical_cdss (your database)
          → Schemas
            → public
              → Tables
                → patients (table 1)
                → assessments (table 2)
                → users (table 3)

You should see 3 tables!

================================================================================
                    VIEW TABLE STRUCTURE
================================================================================

To see table columns (attributes):

1. Right-click on a table (e.g., patients)
2. Click "Properties"
3. Click "Columns" tab
4. You see all attributes:
   - id (INTEGER) - Primary Key
   - name (VARCHAR) - Text
   - age (INTEGER) - Number
   - email (VARCHAR) - Email
   - phone (VARCHAR) - Phone
   - created_at (TIMESTAMP) - Date/Time
   - updated_at (TIMESTAMP) - Date/Time

Each table shows its own columns.

================================================================================
                      VIEW TABLE DATA
================================================================================

To see data in a table:

1. Right-click on table (e.g., assessments)
2. Select "View/Edit Data" → "All Rows"
3. New tab opens showing:
   - All columns (blood_sugar, bmi, age, bp, risk_score, etc.)
   - All rows (each assessment record)
   - Data is sortable and filterable

Example data view:
  id | patient_id | blood_sugar | bmi | age | risk_score | risk_category
  1  | 1          | 150         | 28  | 45  | 72.5       | High
  2  | 2          | 95          | 23  | 30  | 18.3       | Low

================================================================================
                         THE 3 TABLES
================================================================================

TABLE 1: patients
  Stores patient information
  
  Columns:
    id (auto-increment primary key)
    name (patient name)
    age (patient age)
    email (contact email)
    phone (contact phone)
    created_at (when record created)
    updated_at (when last updated)

TABLE 2: assessments
  Stores assessment results
  
  Columns:
    id (auto-increment primary key)
    patient_id (links to patients table)
    blood_sugar (mg/dL)
    bmi (kg/m²)
    age (years)
    blood_pressure (mmHg)
    risk_score (0-100%)
    risk_category (Low/Medium/High)
    blood_sugar_status (Normal/High/etc)
    bmi_category (Normal/Obese/etc)
    bp_category (Normal/High/etc)
    recommendations (text recommendations)
    created_at (when created)
    updated_at (when updated)

TABLE 3: users
  Stores user accounts
  
  Columns:
    id (auto-increment primary key)
    username (login name)
    email (user email)
    password_hash (encrypted password)
    created_at (account creation date)
    updated_at (last update)

================================================================================
                      TABLE RELATIONSHIPS
================================================================================

Foreign Key:
  assessments.patient_id → patients.id
  
Meaning:
  Each assessment belongs to one patient
  One patient can have many assessments

How to see it in pgAdmin:
  1. Right-click assessments table
  2. Properties → Foreign Keys tab
  3. You see: patient_id references patients(id)

================================================================================
                         RUN SQL QUERIES
================================================================================

In pgAdmin, you can run SQL queries:

1. Top menu → Tools → Query Tool
2. Write your SQL:
   
   SELECT * FROM assessments;
   SELECT COUNT(*) FROM patients;
   SELECT AVG(risk_score) FROM assessments;
   
3. Press F5 or click Execute
4. See results below

Useful queries:
   -- Count patients
   SELECT COUNT(*) FROM patients;
   
   -- Count assessments
   SELECT COUNT(*) FROM assessments;
   
   -- Average risk score
   SELECT AVG(risk_score) FROM assessments;
   
   -- High-risk assessments
   SELECT * FROM assessments WHERE risk_score > 70;
   
   -- Patient with most assessments
   SELECT patient_id, COUNT(*) FROM assessments GROUP BY patient_id;

================================================================================
                          TROUBLESHOOTING
================================================================================

Problem: Can't connect to database
→ PostgreSQL not running
→ Start: Windows Services → postgresql-x64-15 → Start
→ Check the PostgreSQL credentials configured for your environment

Problem: No tables showing
→ Run Flask app first: python app.py
→ This creates the tables automatically
→ Then refresh pgAdmin

Problem: No data in tables
→ Create assessments in Flask app first
→ Visit http://localhost:5000/assessment
→ Submit an assessment
→ Then refresh pgAdmin

Problem: Can't find pgAdmin
→ Windows Start Menu → Search "pgAdmin"
→ Or visit: http://localhost:5050

================================================================================
                       EXPORT & BACKUP
================================================================================

Export table to CSV:
  1. Right-click table
  2. View/Edit Data → All Rows
  3. Right-click column header → Export

Backup entire database:
  1. Right-click database
  2. Click "Backup"
  3. Choose format (Custom recommended)
  4. Save backup file

Restore from backup:
  1. Right-click database
  2. Click "Restore"
  3. Select backup file
