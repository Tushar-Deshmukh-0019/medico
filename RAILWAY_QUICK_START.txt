================================================================================
                           5-MINUTE SETUP
================================================================================

STEP 1: Push Code to GitHub (1 minute)

  1. Initialize git:
     cd c:\medical_cdss
     git init
     git config user.name "Your Name"
     git config user.email "your@email.com"

  2. Add and commit:
     git add .
     git commit -m "Medical CDSS deployment"

  3. Create GitHub repo at https://github.com/new
     Name: medical-cdss

  4. Push code (copy commands from GitHub):
     git remote add origin https://github.com/USERNAME/medical-cdss.git
     git branch -M main
     git push -u origin main

STEP 2: Create Railway Project (1 minute)

  1. Go to https://railway.app
  2. Sign up (use GitHub login for easier setup)
  3. Click "Create New Project"
  4. Select "Deploy from GitHub"
  5. Select your "medical-cdss" repository
  6. Railway starts deploying automatically!

STEP 3: Add PostgreSQL (1 minute)

  1. In Railway Dashboard
  2. Click "Add Service"
  3. Select "PostgreSQL"
  4. Railway creates database automatically
  5. DATABASE_URL is set automatically

STEP 4: Set Environment Variables (1 minute)

  1. Click your Flask app service
  2. Go to "Variables"
  3. Add:
     FLASK_ENV = production
     FLASK_DEBUG = False
  
  4. DATABASE_URL is already set by Railway

STEP 5: Get Your Public URL (1 minute)

  1. Click your Flask app service
  2. Look for "Public URL"
  3. Visit URL in browser
  4. Your app is LIVE! 🎉

================================================================================
                        KEY FILES NEEDED
================================================================================

Your project MUST have:

1. Procfile (tells Railway how to run your app)
   Content: web: gunicorn app:app

2. runtime.txt (specifies Python version)
   Content: python-3.10.13

3. requirements.txt (all dependencies)
   Content: Flask, psycopg2, SQLAlchemy, gunicorn, etc.

4. app.py (your Flask application)

5. Code in GitHub repository

================================================================================
                       TROUBLESHOOTING
================================================================================

Problem: "Deployment failed"
→ Check logs: Railway Dashboard → Deployments → View logs
→ Look for error messages
→ Fix locally and push again

Problem: "ModuleNotFoundError"
→ Update requirements.txt: pip freeze > requirements.txt
→ Commit and push
→ Railway redeploys

Problem: "Can't connect to database"
→ Verify PostgreSQL service exists
→ Check DATABASE_URL is set
→ Wait a minute for database to initialize

Problem: "App crashes after deploy"
→ Check logs for error
→ Verify Procfile is correct
→ Verify app.py runs with: python app.py

Problem: "Can't find public URL"
→ In Railway Dashboard
→ Click your app service
→ Scroll right to find "Public URL"
