STEP 1: CREATE THE DATABASE (1 minute)

1. Open Command Prompt
2. Run:
   psql -U postgres -h localhost

3. When prompted, enter the password you configured for PostgreSQL.

4. You'll see: postgres=#

5. Copy-paste this command:
   CREATE DATABASE medical_cdss;

6. You should see: CREATE DATABASE

7. Exit:
   \q

Done! Database created.

================================================================================

STEP 2: START THE APP

1. Open Command Prompt
2. Navigate to project:
   cd c:\medical_cdss

3. Run:
   python app.py

4. You should see:
   ✓ Database initialized successfully
   * Running on http://127.0.0.1:5000

Done! App running.

================================================================================

TROUBLESHOOTING:

Problem: "FATAL: database does not exist"
→ You haven't created the database yet (Step 1)

Problem: "Connection refused"
→ PostgreSQL is not running, start it from Windows Services

Problem: "Password authentication failed"
→ Check your PostgreSQL password configuration

Problem: Can't find psql command
→ Add PostgreSQL to PATH:
   "C:\Program Files\PostgreSQL\15\bin\psql" -U postgres
