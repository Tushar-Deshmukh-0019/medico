================================================================================
                      PART 3: RAILWAY SETUP
                        (5 minutes)
================================================================================

STEP 1: Create Railway Account

  Go to: https://railway.app
  Click "Get Started" or "Start for Free"
  
  Option A: Sign up with GitHub (recommended!)
    Click "Continue with GitHub"
    Authorize Railway
    Done!
  
  Option B: Sign up with email
    Enter email
    Create password
    Verify email
    Done!

STEP 2: Create New Project

  After login, you're in Railway Dashboard
  
  Look for: "Create New Project" button
  Click it
  
  Select: "Deploy from GitHub"
  
  GitHub Authorization:
    Click "Authorize Railway App"
    Railway gets permission to access your repos
    This is SAFE - Railway is trusted

STEP 3: Select Your Repository

  After authorization, you see your GitHub repos
  
  Find and click: medical-cdss (your repo)
  
  Railway asks: Which branch?
  Select: main
  
  Click "Deploy"
  
  RAILWAY STARTS DEPLOYMENT!

WHAT'S HAPPENING:
  ✓ Railway reads your code from GitHub
  ✓ Railway reads Procfile (how to run)
  ✓ Railway reads requirements.txt (dependencies)
  ✓ Railway installs everything
  ✓ Railway starts your app
  → You can watch in Dashboard

  No manual setup needed!

================================================================================
                    PART 5: ENVIRONMENT VARIABLES
                       (2 minutes)
================================================================================

STEP 1: Open Variables Tab

  In Railway Dashboard:
  
  Click: Your Flask app service
  Look for: "Variables" tab
  Click it

STEP 2: Add Variables

  You should see:
    DATABASE_URL = [auto-set by Railway]
  
  Add these:
    ┌────────────────────────────────────┐
    │ Key: FLASK_ENV                     │
    │ Value: production                  │
    │ [Add Variable]                     │
    └────────────────────────────────────┘
    
    ┌────────────────────────────────────┐
    │ Key: FLASK_DEBUG                   │
    │ Value: False                       │
    │ [Add Variable]                     │
    └────────────────────────────────────┘

STEP 3: Save Variables

  After adding each, click: "Add Variable"
  
  Now you have:
    ✓ DATABASE_URL (automatic)
    ✓ FLASK_ENV = production
    ✓ FLASK_DEBUG = False

WHAT THESE DO:
  DATABASE_URL = Connects to Railway's PostgreSQL
  FLASK_ENV = Tells Flask it's production (not debug)
  FLASK_DEBUG = Disables debug mode (more secure)
