DATABASE TABLES
================================================================================

PATIENTS TABLE
├─ id (Integer) - Unique ID
├─ name (String) - Patient name
├─ email (String) - Email address
├─ phone (String) - Phone number
├─ date_of_birth (Date) - DOB
├─ gender (String) - Gender
├─ created_at (DateTime) - Record created
└─ updated_at (DateTime) - Last updated

ASSESSMENTS TABLE
├─ id (Integer) - Assessment ID
├─ patient_id (Integer) - Reference to patient
├─ blood_sugar (Float) - Blood sugar level
├─ bmi (Float) - Body Mass Index
├─ age (Integer) - Patient age
├─ blood_pressure (Float) - BP mmHg
├─ risk_score (Float) - Calculated risk (0-100%)
├─ risk_category (String) - low/medium/high
├─ blood_sugar_status (String) - Status category
├─ bmi_category (String) - BMI category
├─ bp_category (String) - BP category
├─ clinical_notes (Text) - Notes
├─ recommendations (Text) - Recommendations
├─ assessment_date (DateTime) - Assessment time
├─ created_at (DateTime) - Record created
└─ updated_at (DateTime) - Last updated

================================================================================
PYTHON QUERIES - DATABASE OPERATIONS
================================================================================

Import queries:
    from database.queries import *

CREATE PATIENT:
    patient = create_patient("John Doe", email="john@example.com")

GET PATIENT:
    patient = get_patient(patient_id=1)

GET ALL PATIENTS:
    patients = get_all_patients()
    for p in patients:
        print(p.name)

CREATE ASSESSMENT:
    assessment = create_assessment(
        patient_id=1,
        blood_sugar=150,
        bmi=28,
        age=45,
        blood_pressure=135,
        risk_score=62.5,
        risk_category="high"
    )

GET PATIENT ASSESSMENTS:
    assessments = get_patient_assessments(patient_id=1)

GET STATISTICS:
    stats = get_risk_statistics()
    print(f"Total: {stats['total']}")
    print(f"Low Risk: {stats['low_percent']}%")
    print(f"High Risk: {stats['high_percent']}%")

GET AVERAGE RISK:
    avg = get_average_risk_score()
    print(f"Average Risk: {avg}%")

SEARCH PATIENTS:
    results = search_patients("John")

================================================================================
OPTIONAL: SWITCH TO MYSQL (Production)
================================================================================

1. INSTALL MYSQL:
   Download from mysql.com or:
   - Windows: choco install mysql
   - Linux: sudo apt-get install mysql-server
   - Mac: brew install mysql

2. CREATE DATABASE:
   mysql -u root -p
   > CREATE DATABASE medical_cdss;
   > CREATE USER 'cdss_user'@'localhost' IDENTIFIED BY 'password';
   > GRANT ALL PRIVILEGES ON medical_cdss.* TO 'cdss_user'@'localhost';
   > FLUSH PRIVILEGES;

3. SET ENVIRONMENT VARIABLE:
   Windows (Command Prompt):
   set DATABASE_URL=mysql+pymysql://cdss_user:password@localhost:3306/medical_cdss
   
   Windows (PowerShell):
   $env:DATABASE_URL = "mysql+pymysql://cdss_user:password@localhost:3306/medical_cdss"
   
   Linux/Mac:
   export DATABASE_URL="mysql+pymysql://cdss_user:password@localhost:3306/medical_cdss"

4. START APPLICATION:
   python app.py
   
   Database will automatically initialize with MySQL!

================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

"No such table: patients"
  → Database not initialized
  → Solution: Run application once to initialize
  → Or: python -c "from app import db, create_app; app = create_app(); db.create_all()"

"Connection refused" (for MySQL)
  → MySQL not running
  → Solution: Start MySQL server (services.msc on Windows)

"Foreign key constraint failed"
  → Patient doesn't exist for assessment
  → Solution: Create patient first, then assessment

"Permission denied" (SQLite)
  → File permissions issue
  → Solution: Check file permissions on medical_cdss.db
